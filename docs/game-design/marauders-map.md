# Marauder's Map

## Fantasy

Игрок не получает готовую Карту Мародёров.

> Игроки постепенно создают её на протяжении школьных лет.

## [CANON] Foundation

Текущая lore-модель фиксирует:
- Мародёры чрезвычайно подробно исследовали Хогвартс;
- James, Sirius и Peter использовали анимагические формы при исследовании;
- использовалась Мантия-невидимка James;
- карта использует Homonculous Charm;
- карта отслеживает людей независимо от некоторых способов маскировки;
- карта содержит персонализированную защитную реакцию на Snape.

См. [Lore & Magic Model](../lore/lore-and-magic.md).

## [GAME] System stack

Marauder's Map:
- Spatial Model
- Discovery State
- Entity Detection
- Identity Resolution
- Position Tracking
- Visualization
- Security
- Behaviour Layer

## Exploration loop

discover → verify → understand → bind to map → test → refine

Разные открытия требуют разных методов:
- физическое посещение;
- наблюдение;
- анимагическая форма;
- мантия;
- разговор;
- эксперимент с чарами.

## Map as progression

Карта должна отражать реальные знания игроков.

Неизвестное место не появляется просто потому, что игрок повысил уровень.

## Limits

Выручай-комната — полезный пример пространства, которое не обязано полностью подчиняться карте.

**[GAME]**

> даже завершённая Карта не должна превращать Хогвартс в полностью решённый уровень.

## UI principle

Карта — diegetic artifact, а не обычный fullscreen GPS.

Она может использоваться как интерфейс, но должна сохранять ощущение физического зачарованного пергамента.
