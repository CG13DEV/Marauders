# Hogwarts Simulation

## Goal

**[GAME]** Хогвартс моделируется как персистентная школьная экосистема, а не как набор спавнящихся NPC.

**[GAME]** Значимый персонаж существует независимо от игрока и от текущего диалога. Диалог — только один из способов взаимодействия с уже существующей сущностью мира.

## Persistent people

Каждый значимый студент и профессор имеет стабильный identity record:

Person
- identity
- house / role
- school_year
- timetable
- location state
- relationships
- personality constraints
- current goals
- beliefs
- knowledge
- semantic memory
- episodic memory
- emotional / salient memory
- academic state
- discipline state
- club memberships
- history

После разговора, конфликта, наказания или совместного события персонаж не возвращается к нулевому состоянию.

## Character model

**[GAME]** Характер задаётся не одной шкалой и не набором диалоговых флагов, а устойчивыми поведенческими ограничениями и приоритетами.

Примеры:
- что персонаж почти никогда не сделает;
- что может сделать только под сильным давлением;
- какие принципы ставит выше формальных правил;
- как относится к риску, власти, унижению, лжи и конфликту;
- какие конкурирующие цели пытается удовлетворить.

Это должно позволять получать правдоподобное поведение даже в ситуации, которую сценарист заранее не предусмотрел.

## Knowledge and beliefs

**[GAME]** NPC не имеет глобального доступа к истине мира.

Знание должно иметь происхождение:
- witnessed;
- told_by;
- overheard;
- inferred;
- read;
- discovered.

Для значимых фактов полезно хранить:
- source;
- confidence;
- timestamp;
- secrecy / willingness_to_share.

Персонаж может знать неполную версию события, ошибаться или считать слух фактом.

**[GAME]** Belief отделяется от fact. Убеждение персонажа о другом человеке или событии может быть устойчивым и ложным и должно влиять на интерпретацию новых действий.

## Memory

**[GAME]** Предпочтительно разделять:

- semantic memory — устойчивые знания о мире и людях;
- episodic memory — лично пережитые события;
- emotional / salient memory — события и выводы, которые заметно изменили отношение.

Не каждое событие хранится навсегда в полном виде. Малые эпизоды могут агрегироваться в отношения и репутацию, а особо значимые остаются отдельными воспоминаниями.

## Relationships

**[GAME]** Отношение между людьми не сводится к единому `relationship score`.

Минимальная модель может включать:
- trust;
- affection;
- respect;
- fear;
- admiration;
- resentment;
- irritation;
- known shared events.

Одинаковое действие игрока может иметь разный смысл для разных NPC из-за их памяти, убеждений и характера.

## Academic year transition

Каждый новый учебный год:
- выпускаются семикурсники;
- существующие ученики переходят на следующий курс;
- появляется новый первый курс;
- обновляются старосты и роли;
- пересобираются расписания;
- меняется набор предметов;
- обновляется состав клубов.

Выпускники не удаляются из сохранения. Они переходят в alumni / external world state и могут возвращаться.

## Exams

**[CANON]**
Особенно важны:
- O.W.L.s — пятый курс;
- N.E.W.T.s — седьмой курс.

**[GAME]**
Результат должен возникать из накопленного состояния, а не из одной мини-игры:

attendance + knowledge + practical skill + preparation → exam result

То же относится к NPC: результаты могут менять их дальнейшие предметы и карьерную траекторию.

## Social groups

Поддерживаются постоянные сообщества со своими:
- участниками;
- правилами вступления;
- расписанием;
- местами встреч;
- репутацией;
- историей.

Примеры:
- Slug Club;
- дуэльные сообщества;
- факультетские группы;
- неформальные компании;
- временные тайные объединения.

**[GAME]** Постоянный дуэльный клуб именно в эпоху Мародёров пока считается авторским решением, если не найден прямой источник.

## Off-screen simulation

История ученика должна продолжаться без участия игрока.

Пример:

Year 3: joins a club  
Year 4: befriends another student  
Year 5: fails an O.W.L.  
Year 6: drops the subject  
Year 7: becomes prefect  
After school: graduates

Игрок может увидеть только часть этой цепочки.

## Character depth tiers

**[GAME]** Персистентность не требует одинаковой когнитивной глубины для всех жителей школы.

Предпочтительные уровни:
- background population — статистическое / событийное существование;
- named NPC — расписание, отношения, базовая память;
- important NPC — goals, beliefs, episodic memory, knowledge provenance;
- core character — полная personality model, долговременная память и сложный social graph.

Это отдельная ось от spatial simulation LOD. Персонаж может быть важным и при этом симулироваться off-screen без Actor.

## Simulation LOD

Не каждый NPC требует одинаковой частоты симуляции.

Предпочтительная архитектура:

near player → full actor simulation  
same location → reduced simulation  
elsewhere school → schedule/event simulation  
off-campus → abstract persistent state

Персистентность не означает, что все персонажи должны тикать как Actor каждый кадр.
