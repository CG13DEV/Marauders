# Animagus System

## Canon foundation

**[CANON]**
James Potter, Sirius Black и Peter Pettigrew тайно становятся незарегистрированными анимагами ради Remus Lupin.

Формы:
- James → stag;
- Sirius → large dog;
- Peter → rat.

Remus не является анимагом.

## Design goal

**[GAME]**
Анимагия — многолетний проект и одна из крупнейших progression arcs игры.

Она не должна открываться обычным skill point.

Игроки должны:
- узнать, что такая магия существует;
- найти знания;
- понять риск;
- подготовить ритуальные / магические условия;
- выполнить длительный процесс;
- пережить возможные ошибки;
- научиться использовать форму.

## Traversal identities

### Peter / rat

Сильная сторона — доступ:
- щели;
- закрытые помещения;
- скрытые маршруты;
- подслушивание;
- мелкомасштабная разведка.

### Sirius / dog

Сильная сторона — sensing и преследование:
- запах;
- поиск следов;
- скорость;
- физическое взаимодействие.

### James / stag

Сильная сторона — пространство и масса:
- скорость;
- пересечение территории;
- взаимодействие с крупными препятствиями;
- защита группы.

### Remus

Не должен ощущаться «персонажем без механики».

Его уникальный слой:
- теория;
- знания;
- магические исследования;
- оборотничество как периодическое изменение world rules.
