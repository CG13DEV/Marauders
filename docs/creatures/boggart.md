# Боггарт (Boggart)

## Краткий образ

Закрытый шкаф начинает скрестись изнутри. Пока дверца закрыта, невозможно знать, что там. Когда её открывают, содержимое становится для наблюдателя самым страшным из того, что он способен вообразить. Опасность боггарта — не в «полоске здоровья», а в персональном столкновении со страхом.

## Подтверждённые свойства

- **[CANON]** Боггарт — меняющий облик **не-существо (non-being)**, никогда по-настоящему не бывшее живым; родственно по этой классификации полтергейстам. Его истинный внешний вид никому не известен.
- **[CANON]** При встрече с человеком принимает облик того, чего тот боится сильнее всего; повышенная пугливость делает человека уязвимее к боггарту.
- **[CANON]** Предпочитает тёмные замкнутые пространства: шкафы, пространство под кроватью и другие укрытия; может выдавать присутствие стуком, скрежетом, движением предмета.
- **[CANON]** Маглы тоже могут ощущать боггарта и иногда мельком видеть его.
- **[CANON]** Для изгнания служит заклинание `Riddikulus`: намерение мага превращает пугающий образ в смешной, а смех рассеивает страх. Боггарт может исчезнуть, но это не означает исчезновения всех боггартов из мира.
- **[CANON]** Связь боггартов с человеческими эмоциями описана как предполагаемая, а не полностью установленная теория происхождения.

**Не утверждаем:** что боггарт читает мысли точным образом, обладает личностью, всегда материально причиняет ту же опасность, что и объект имитации, или имеет постоянную «нейтральную модель». Эти детали не установлены и не нужны для базовой механики.

## Поведение в игре

- **[GAME]** Боггарт — событийная сущность с состояниями `hidden → disturbed → manifested → disrupted/banished`, а не патрульный противник.
- **[GAME]** Страх не вычисляется из реальной психологии человека за экраном: для каждого игрового персонажа используются **заранее описанные или сюжетно подтверждённые** `fear_themes`, способные меняться после значимых событий.
- **[GAME]** Проявление выбирается по доступному наблюдателю и контексту; визуальный образ выбирается из небольшой авторской библиотеки представлений о страхе. Одна тема может допускать несколько постановок, без утверждения «боггарт всегда выглядит так».
- **[GAME]** Укрытие существует независимо от игрока: шкаф может шуметь до встречи; другие NPC способны заметить странность, открыть его, убежать или предупредить товарищей.
- **[GAME]** В кооперативе при нескольких наблюдателях выбор того, чей страх проявится, определяется прозрачным приоритетом (например, ближайший наблюдатель с прямой видимостью); игроки могут осознанно менять расстановку. **Это правило игры, не подтверждённое универсальное свойство боггартов.**

## Страх, намерение, `Riddikulus`

- **[GAME]** Успешная защита — не просто «нажать кнопку спелла». Персонаж должен знать заклинание, иметь возможность сосредоточиться и сформировать подходящее комическое преобразование для **текущего** проявления.
- **[GAME]** Смешная форма определяется эффектом магии над воспринимаемым образом; не требуется бесконечно генерировать 3D-модели. Достаточно конечного набора обратимых замен, эффектов, реквизита и реакций.
- **[GAME]** Неудача может оставить боггарта активным, усилить смятение или заставить персонажа отступить. Не вводить XP-урон как основной эффект страха.
- **[GAME]** Помощь друзей даёт возможности: предупредить, показать пример, отвлечь внимание, поддержать или самому принять позицию перед укрытием. Не делать кооператив обязательным.
- **[GAME]** Увиденное проявление может стать **социальной информацией**: кто-то узнал чужой страх; свидетель способен проявить такт, сохранить тайну или позднее использовать знание. Истина о страхе персонажа при этом хранится в данных мира, не придумывается диалоговой моделью.

## Место в Хогвартсе

- **[GAME]** Возможны заброшенный чулан, захламлённая комната, старый сундук, помещение для практики защиты от тёмных искусств. Точное расположение и конкретные события в 1971–1978 — авторский выбор.
- **[GAME]** Боггарт позволяет обнаружить тайну без квестовой иконки: заметить царапанье, сравнить рассказы нескольких учеников, исследовать источник шума.
- **[GAME]** Не переносить урок профессора Люпина из *Prisoner of Azkaban* в 1970-е: Ремус тогда ученик, не преподаватель.
- **[GAME]** Никакого автоматического «сканера страхов» для всех NPC: достаточно курируемых тем важных персонажей и безопасного дефолта для фоновых жителей.

## Технический контур

**[GAME]** `BoggartState { id, hiding_place, mode, observer_id?, manifestation_id?, disruption_state }`

`CharacterFearContext { character_id, fear_themes[], story_flags, knowledge_of_riddikulus }`

Укрытие + событие наблюдения → выбор наблюдателя → выбор допустимого проявления → реакция персонажей → применение магии/смех → validated world event → персистентный результат (исчезновение, сообщение о находке, память свидетеля).

**Не требуется:** скрытая форма в качестве канонического «оригинала», генеративный AI для чтения страхов, физическая симуляция «настоящего монстра» под любой маской.
