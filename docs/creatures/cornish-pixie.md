# Корнуэльский пикси (Cornish pixie)

## Краткий образ

Крошечное электрически-синее создание, которое обожает беспорядок. Поодиночке выглядит почти игрушечным; стайка быстро превращает комнату в катастрофу: пропадают вещи, летят чернильницы, ученики обнаруживают себя там, куда не собирались попадать.

## Подтверждённые свойства

- **[CANON]** Корнуэльский пикси родом из Корнуолла на юго-западе Англии; рост — до восьми дюймов (около 20 см); окраска — ярко-синяя.
- **[CANON]** Летает **без крыльев**. Сочетает маленькие размеры с несоразмерной физической силой; пикси способны поднять человека за уши и унести на высоту.
- **[CANON]** Озорной нрав, любовь к проделкам и разрушению порядка; классификация Министерства магии — **XXX**.
- **[CANON]** Участники группы могут действовать совместно; известны нападения на предметы обстановки и школьные принадлежности.
- **[CANON]** Замораживающие чары (*Immobulus*) способны обездвижить пикси. Это свойство самих чар, а не специальная «атака по пикси».

**Визуальная граница:** крылатый образ встречается в экранизациях; для основного игрового образа принимаем бескрылый книжный вариант. **[GAME]** Любая альтернативная стилизация требует отдельного осознанного решения, а не маркировки CANON.

## Поведение в игре

- **[GAME]** Пикси — физические агенты среды, не обычный боевой моб. Ищут доступные вещи, перехватывают переносимые объекты, дёргают одежду, сбрасывают предметы, мешают работать и иногда объединяются для подъёма более крупной цели.
- **[GAME]** Модель предпочтений опирается на состояние мира: `visible_object`, `grabbable`, `movable`, `accessible`, `disturbance`, `nearby_pixies`. Не нужна сложная психология и не нужен отдельный скрипт для каждого предмета.
- **[GAME]** Стая поддерживает локальное возбуждение/внимание; шум, движение предметов и реакция присутствующих могут переключать цели. Это **дизайнерская модель**, не утверждение о канонической биологии.
- **[GAME]** Для группового подъёма тяжёлого объекта проверяются число участвующих пикси, разрешённый захват и физические ограничения. Перемещение и столкновения авторитетно рассчитывает движок.
- **[GAME]** Вне зоны активной симуляции стаю можно агрегировать до состояния `location / group_size / activity / disturbance`, сохраняя последствия, а не каждый полёт.

## Взаимодействия

| Действие | Системный результат |
| --- | --- |
| Попытаться схватить пикси рукой | **[GAME]** Трудно из-за скорости и полёта; возможна физическая ловушка и помощь окружения. |
| Применить `Immobulus` | **[CANON]** Чары способны обездвижить цель; **[GAME]** пикси теряет управление полётом на время эффекта, дальнейшее движение подчиняется физике. |
| Убрать мелкие предметы / закрыть доступ | **[GAME]** Уменьшает число доступных целей для проказ; не выключает пикси из мира. |
| Встретить стаю вдвоём или вчетвером | **[GAME]** Игроки могут отвлекать, ловить, страховать друг друга и предотвращать падение вещей без жёсткого кооперативного сценария. |

## Место в Хогвартсе

- **[GAME]** Возможные контексты: практическое занятие с контролируемыми существами, случайно открытый контейнер, недосмотр за привезённой клеткой или последствия ученической шалости. **Конкретное присутствие пикси в школе эпохи Мародёров не подтверждено каноном**.
- **[GAME]** Возникают материальные последствия: нарушен порядок, разбросаны вещи, ученики бегут за помощью, преподаватель меняет доступ к помещению, Филч замечает беспорядок.
- **[GAME]** Не копировать историю с уроком Локхарта в 1990-х в школьные годы 1971–1978.

## Технический контур

**[GAME]** `CreatureState { id, species, location, activity, held_object?, group_id?, temporary_effects }`

Система принимает событие → выбирает допустимое действие по affordances → проверяет дистанцию / захват / чары → выполняет движение/физику → записывает устойчивое последствие.

**Не требуется:** LLM, индивидуальные диалоги, отдельные анимации на каждую разрушаемую вещь, универсальная шкала агрессии.
