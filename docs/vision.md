# Vision

## Рабочая формулировка

**Maradeurs** — кооперативная системная игра о школьных годах Мародёров в Хогвартсе.

Игрок выбирает одного из четырёх персонажей:
- James Potter;
- Sirius Black;
- Remus Lupin;
- Peter Pettigrew.

Игра охватывает несколько учебных лет, а не один застывший семестр.

## Fantasy

Не «стать очередным избранным волшебником», а:

> быть талантливым школьником внутри живого Хогвартса, нарушать правила, изучать устройство магии, исследовать замок и постепенно создать вещи и знания, которые позже станут легендой.

Карта Мародёров и анимагия — не стартовые способности и не награды за катсцену. Это результаты многолетнего опыта игрока.

## Отличие от обычной open-world RPG

Не:

map marker → quest → combat arena → reward

А:

need / curiosity → observation → preparation → systemic action → consequence → persistent world change

## Хогвартс

Хогвартс — главный игровой объект.

Он должен быть:
- большим;
- неоднозначным;
- частично скрытым;
- меняющимся;
- социально живым;
- недостаточно изученным даже после многих часов.

Игрок постепенно понимает школу настолько хорошо, что способен создать Карту Мародёров, но даже карта не обязана описывать Хогвартс полностью.

## Кооператив

Кооператив строится не вокруг MMO-ролей, а вокруг разных способов взаимодействия с пространством, знаниями и людьми.

Каждый персонаж должен оставаться полноценным в одиночной игре, но группа открывает решения, которых нет у одного игрока.
