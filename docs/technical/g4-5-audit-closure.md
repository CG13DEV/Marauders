# G4 audit: исправления #78, #79, #80

**[GAME]** Ревизия интеграции G4.1–G4.5 и регрессионные барьеры. Патч PR #81 на ветке `fix/g4-5-audit-p1-research-integrity`. Документ описывает введённые контракты; результат CI и фактические замеры фиксируются отдельно в GitHub Actions, а не подменяются обещаниями.

## #78 — эксперимент имеет физический срок жизни

**60 игровых минут (6 тиков)** — максимальный срок эксклюзивной «аренды» физического предмета активной попыткой. На каждом шаге школы после обновления общего времени, **до** выбора следующего действия NPC, `magicResearch.expire(minute)` завершает просроченные бронирования. Событие `magic_trial_abandoned` с `cause:'expired'` содержит владельца, гипотезу, предмет и момент. Оно аудируемо и воспроизводится.

Игрок/NPC может применить `abandon_magic_trial(actor)` без идентификатора удалённого пера, физической комнаты и зрения. Команда действует **только** на собственную попытку. В журнале остаётся гипотеза, но никогда не возникает фиктивное «успешное наблюдение». При подмене эффекта результат `trial_interrupted` также освобождает объект и отмечает событие. При честном завершении через `record_magic_trial` отпускание предмета атомарно с фиксацией данных.

`reserved:Map<objectId,actorId>` — лишь приватный индекс **того же** world-local `active`; он не является второй авторитетной моделью. Индекс восстанавливается при загрузке checkpoint и journal и отвергает двойное владение.

**Гейты:** уход за пределы комнаты, ослепление в восстановленном мире, добровольное прекращение, незавершённая аренда через save/load, тайм-аут, повторное использование предмета другим учеником, две одновременные разные физические цели, нормальный 20-минутный опыт.

## #79 — без компетентного учителя нет новой формулы

Перед передачей теории расписанного `lesson.spell` теперь требуется **личное знание этой формулы у реально присутствующего `lesson.teacher`**. Преподаватель не может «создать» концепт из одной строки учебного графика. Магические примитивы по-прежнему требуют осведомлённого преподавателя.

Старые лабораторные и текстовые фикстуры исправлены: они явно создают и обучают настоящего преподавателя, а не отменяют новую проверку. Штатные преподаватели `Charms` (в том числе ассистенты младших курсов из `foundations-27`) знают действительно преподаваемый учебный `Lumos`. Другие предметы не получают от этого новых скрытых знаний. Успешно посещённый урок даёт **conceptual**, не автоматически `guided`/`independent`.

**Гейты:** неграмотный преподаватель, отсутствующий преподаватель, квалифицированный преподаватель и реально присутствующий ученик, ученик-прогульщик, профессиональное владение конкретным примитивом, journal/checkpoint provenance.

## #80 — реальный 600+ school science и сравнительный baseline

`visibleMagicObjects` больше **не** клонирует магические объекты всего мира на каждый запрос: локальная ECS-комната запрашивается по `MagicTarget + LocatedIn(room)`, и копируются только **видимые** позиции и яркость. `magicResearch.busy(object)` использует мировой индекс занятости за O(1), а не полный snapshot чужих журналов.

**Контролируемый опыт:** `npm run controlled-spell-demo`. В той же комнате размещаются три одинаково подготовленных физических пера. Исследователь воздействует именованным **чёрным ящиком** `Wingardium Leviosa` и двумя самостоятельно построенными кандидатами. Для всех применяется одинаковый толчок. Отчёт собирает только `visibleMagicObjects` — наблюдаемые координаты и свет **до/после**, без скрытой массы, исходного AST и оценки «раскрыт оригинал».

**Профиль масштабирования:** `npm run magic-population-soak`. Ровно тот же **масштаб 600+ учеников** (`research-600`, `96-all`), тот же недельный календарь и 560 десятиминутных тиков прогоняются в двух режимах `legacy` и `living-g4-5`. Печатаются количество NPC, число реально завершённых опытов, остаток незавершённых аренд, процессорное время, время на тик и peak heap. Гейт проваливается при отсутствии минимум двух исследователей, нескольких записанных наблюдений, реально посещённых уроков, просроченных аренд или при CPU >8× сопоставимого населения. Это **экспериментальный предохранитель**, а не SLA релизного игрового клиента.

Тест двух независимых исследователей подтверждает checkpoint и journal при **одновременных** опытах с разными предметами.

## Границы, которые сознательно не закрываем этим патчем

- Здесь ещё нет полноценного фреймового WebGL-редактора заклинаний и точной линии зрения внутри комнаты; текущая физика обновляется один раз в 10 игровых минут.
- Измерение яркости/позиции при общей комнате — первый уровень наблюдаемости, не полноценная система приборов и лабораторной погрешности.
- Ученик ещё не придумывает неизвестные магические примитивы и не публикует находки в библиотеке. Заранее ограничены два контроллера.
- Политика контроля реального кинематического эффекта одного заклинания не доказывает устройство книжной магии: **CANON ≠ GAME**.
