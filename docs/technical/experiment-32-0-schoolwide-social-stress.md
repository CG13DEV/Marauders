# Эксперимент 32.0 — социальная архитектура на масштабе школы

**Тип:** [GAME]. **Статус:** контрольная и полная семидневные симуляции прошли в [CI #38025416355](https://github.com/CG13DEV/Marauders/actions/runs/38025416355); дополнительная проверка конфликтов расписания ожидает подтверждения. Не считать доказанным многолетний масштаб.

## Граница того, что мы знаем

Предыдущий #30.8 создавал 634 физических жителей, но не включал одновременно весь контекстный пакет 31.4–31.12 для каждого. Эксперименты 31.8–31.12 устанавливают *причинную корректность* на небольших независимых сценариях. Производительность полномасштабной социальной политики ранее не измерялась.

## Честное развёртывание

Фиксированная школа содержит 600 учеников, 25 преподавателей и 9 других жителей (634 всего). В существующей конфигурации 624 обладают нормальным `DailyLifePlan` и могут получить социальную политику без нарушения прежней физики: **600 учеников и 24 преподавателя**. Биннс (призрак-преподаватель), Филч, кошка Норрис, директор, привидения и Пивз сохраняют специальные правила. Насильно назначать всем приёмы пищи, социальные привычки и человеческий режим не следует.

На всех 624 одновременно включаем:

- `socialInvitations`, `relationshipLearning`, `contextualRelationships`;
- `socialChoice: reflective`, `repairInitiative`;
- `repairResponse` с фиксированной неоднородностью `guarded/open`.

Мы **не добавляем** новые социальные счётчики, глобальные знания или предписания каждому школьнику с кем говорить. Физическое расписание, существующие намерения и маршруты сохраняются.

## Контроль и наблюдаемость

Две независимые сессии Node.js на одной GitHub Actions машине: `npm run social-school-stress -- --baseline` и `npm run social-school-stress -- --all-eligible`, каждая симулирует семь дней по 144 тика (1008 тиков). Замеряем CPU-стоимость `world.step()`, p50/p95/p99/max тика, действия, попытки приглашений и свободные ответы, нарушения обязательств, предложения исправлений, траектории обучения/посещаемости, heap после GC (диагностика), размер checkpoint и идентичность следующих 12 тиков после восстановления. В CI участвует и стандартный недельный soak #30.8.

Критерии корректности: отсутствуют невалидные перемещения, уроки корректно завершаются, личные данные сохраняются; в школе реально происходят беседы, приглашения и добровольные ответы. Измерение производительности **не означает** заранее обещанного FPS. Локальная 3D сцена, рендер, UI и физика UE остаются вне исследования. Отсутствие `repair` в естественном недельном мире не отменяет доказательства корректности 31.8, но ограничивает вывод о нагрузке именно этого редкого механизма.

## Измерения реального семидневного прогона

Источник: полный лог GitHub Actions [#38025416355](https://github.com/CG13DEV/Marauders/actions/runs/38025416355), отдельные Node-процессы с одинаковой топологией, расписанием и population=634.

| Метрика | Обычная школа | Социальная политика на 624 NPC |
|---|---:|---:|
| Время внутри `world.step()` за 1008 тиков | 7 887 мс | 9 640 мс |
| p50 тика | 4,58 мс | 6,61 мс |
| p95 тика | 25,52 мс | 26,76 мс |
| p99 тика | 34,59 мс | 42,46 мс |
| Авторитетных действий NPC | 205 839 | 205 743 |
| Физически предложенных встреч | 410 | 421 |
| Принятых встреч | 313 | 331 |
| Отказов | 97 | 90 |
| Состоявшихся встреч | 313 | 331 |
| Неявок | 0 | 0 |
| Предложений исправить проступок | 0 | 0 |
| Heap после GC по завершении седьмого дня, **до** checkpoint | 36 MiB | 38 MiB |
| Размер V2 checkpoint | 15,25 MiB | 15,35 MiB |

Время шагов увеличилось примерно на **22,2%**, p95 — примерно на **4,9%**. Все 624 допустимых акторов включены, 0 невалидных перемещений, 0 пропущенных уроков, 12 тиков после сохранения/восстановления идентичны. **Но** в обычной школьной неделе приглашения и согласия есть, а неявок нет. Поэтому нагрузка и восстановление самой причинной памяти о нарушениях пока не были активированы массой естественных эпизодов; это отрицательный результат диагностики покрытия сценария, не повод выдавать пройденную неделю за полное доказательство.

`finalAfterGcHeapMiB` после сериализации, восстановления и глубокого сравнения содержит временные расходы **аудита**, поэтому его нельзя сравнивать напрямую с heap после GC на конце дня 7. Значения RSS отдельного Node-процесса не являются точным потреблением ECS-персонажа.

## Дополнительный контролируемый стресс: вечерняя самоподготовка

Отдельная вилка `--conflict-full`: 120 из 600 учеников до первого тика получают по два дополнительных вечерних школьных занятия в настоящих учебных пространствах (дни 1 и 3, 19:10–20:20). Даты намеренно перекрывают обычную вечернюю встречу 19:40. Ни приглашения, ни согласие, ни опоздание, ни попытка восстановить обещание не вписываются скриптом: всё решают исходные свободные политики, расписание, комнаты, маршрут и личный опыт. Новую проверку следует читать отдельно от прямого сравнения baseline/all-eligible, потому что расписания в ней отличаются. Числа заполнить только после CI.
