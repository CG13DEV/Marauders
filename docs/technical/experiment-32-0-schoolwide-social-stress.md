# Эксперимент 32.0 — социальная архитектура на масштабе школы

**Тип:** [GAME]. **Статус:** IMPLEMENTED; results pending GitHub Actions. Do not claim verified scaling until both full-week baseline and enabled runs pass.

## Граница того, что мы знаем

Предыдущий #30.8 создавал 634 физических жителей, но не включал одновременно весь контекстный пакет 31.4–31.12 для каждого. Эксперименты 31.8–31.12 устанавливают *причинную корректность* на небольших независимых сценариях. Производительность полномасштабной социальной политики ранее не измерялась.

## Честное развёртывание

Фиксированная школа содержит 600 учеников, 25 преподавателей и 9 других жителей (634 всего). В существующей конфигурации 624 обладают нормальным `DailyLifePlan` и могут получить социальную политику без нарушения прежней физики: **600 учеников и 24 преподавателя**. Биннс (призрак-преподаватель), Филч, кошка Норрис, директор, привидения и Пивз сохраняют специальные правила. Насильно назначать всем приёмы пищи, социальные привычки и человеческий режим не следует.

На всех 624 одновременно включаем:

- `socialInvitations`, `relationshipLearning`, `contextualRelationships`;
- `socialChoice: reflective`, `repairInitiative`;
- `repairResponse` с фиксированной неоднородностью `guarded/open`.

Мы **не добавляем** новые социальные счётчики, глобальные знания или предписания каждому школьнику с кем говорить. Физическое расписание, существующие намерения и маршруты сохраняются.

## Контроль и наблюдаемость

Две независимые сессии Node.js на одной GitHub Actions машине: `npm run social-school-stress -- --baseline` и `npm run social-school-stress -- --all-eligible`, каждая симулирует семь дней по 144 тика (1008 тиков). Замеряем CPU-стоимость `world.step()`, p50/p95/p99/max тика, действия, попытки приглашений и свободные ответы, нарушения обязательств, предложения исправлений, траектории обучения/посещаемости, heap после GC (диагностика), размер checkpoint и идентичность следующих 12 тиков после восстановления. В CI участвует и стандартный недельный soak #30.8.

Критерии корректности: отсутствуют невалидные перемещения, уроки корректно завершаются, личные данные сохраняются; в школе реально происходят беседы, приглашения и добровольные ответы. Измерение производительности **не означает** заранее обещанного FPS. Локальная 3D сцена, рендер, UI и физика UE остаются вне исследования. Отсутствие `repair` в естественном недельном мире не отменяет доказательства корректности 31.8, но ограничивает вывод о нагрузке именно этого редкого механизма.
