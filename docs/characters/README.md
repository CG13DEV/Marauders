## Design rule

**[GAME]** A character must remain coherent if free-form dialogue is disabled.

LLM may render speech or propose a decision, but identity, memory, beliefs, knowledge boundaries, goals and persistent consequences belong to the simulation.

Different characters should stress different parts of the shared model instead of becoming the same generic AI agent with different tone prompts.
